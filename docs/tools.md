# Simulated tools

_Generated by `robot_eval.tools.docgen` from the live registry and real simulator output; `tests/unit/test_docs.py` fails if this file is stale._

All tools are local, deterministic and simulation-only (no network, no hardware). Units: metres and degrees. Coordinates: x right, y up, origin of the workcell frame. Inputs are strictly validated: unknown fields, strings where numbers are expected, booleans, NaN/inf and |value| > 1000 are rejected with `INVALID_ARGUMENT` and **no state change**.

## Tool list

| tool | state-changing | description |
|---|---|---|
| `get_workcell_state` | no | Return the full simulated workcell: workspace bounds, robot base, reach band, clearance margins, obstacles (circles), joint limits and the current end-effector position. Units: metres and degrees. |
| `check_reachability` | no | Check whether a target point (metres) is inside the workspace AND within the robot's reach band (reach_min <= distance from base <= reach_max, inclusive). Ignores obstacles and clearance. |
| `check_collision` | no | Check whether a single point lies inside or on the edge of any circular obstacle (touching counts as a collision). Does not check margins (use check_clearance) or path segments (use validate_path). |
| `check_clearance` | no | Compute the minimum distance from a point to the nearest obstacle surface and compare it with a required margin (default: the workcell clearance margin). Meeting the margin exactly is acceptable; a collision always fails. |
| `validate_joint_limits` | no | Check simulated joint angles (degrees) against the declared inclusive joint limits. Joints: shoulder, elbow, wrist. Unknown joint names are rejected. |
| `plan_path` | no | Plan a deterministic collision-free straight or detour path between two points using a visibility-graph planner. Fails with a structured error if an endpoint is unsafe or no path is found. Does not move the robot. |
| `validate_path` | no | Independently check an ordered list of waypoints: every waypoint (bounds, reach, collision, clearance) and every segment between them (collision, clearance, inner reach limit). Does not move the robot. |
| `estimate_operation_feasibility` | no | Check preconditions for a simulated operation at a point: 'weld_point' needs the stricter weld clearance, 'inspect_point' the normal margin; both need the point in bounds, reachable and collision-free. Simulation only; does not control anything. |
| `move_end_effector` | **yes** | STATE-CHANGING. Move the simulated end effector in a straight line from its current position to (x, y). The simulator independently rejects unsafe moves (out of bounds, unreachable, collision, insufficient clearance, unsafe path) and leaves the state unchanged. |
| `inspect_tool_schema` | no | List the available tools, or return the description and JSON argument schema of one tool. |
| `get_simulation_diagnostics` | no | Return the logged record (tool, arguments, ok, error code, state_changed) of a previous simulated operation by id, or of the most recent one when no id is given. |

## Semantics fixed by the simulator (and mirrored independently by the exact-arithmetic oracle)

* Obstacles are closed discs; **touching = collision** (clearance <= 0).
* A required clearance margin is met when clearance >= margin (**equality is safe**).
* Reach band, workspace and joint limits are closed intervals (equality is inside).
* Violation precedence for the *primary* error code: OUT_OF_BOUNDS > TARGET_UNREACHABLE > COLLISION > INSUFFICIENT_CLEARANCE > PATH_UNREACHABLE > PATH_COLLISION > PATH_CLEARANCE. All violated codes are listed in `data.violation_codes`.
* Only `move_end_effector` mutates the world (end-effector pose), and only after every check passes. Failed or rejected calls leave the pose unchanged.
